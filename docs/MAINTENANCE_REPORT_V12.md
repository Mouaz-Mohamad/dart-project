# تقرير صيانة Dart — V12

التاريخ: 2026-09-14

## النتيجة

تم إصلاح حجم كلمات الـHero، وإظهار الخصم في كروت المنتجات، وإضافة تراجع حقيقي وآمن لمراحل المرتجعات، وإعادة تنظيم CSS للموقع حسب البنية المطلوبة. لم تُجمع ملفات JavaScript الخاصة بالصفحات، وظلت تنسيقات الداشبورد منفصلة عن الموقع، ولم يتغير `CSS/base.css` بايتًا واحدًا.

## شرح الإصلاحات

### Hero Words

كان الداشبورد يحفظ الحجم كرقم مثل `50`، ثم كان الموقع يعيّن الرقم مباشرة إلى `element.style.fontSize`. القيمة `50` بلا وحدة CSS غير صالحة، فيتجاهلها المتصفح. أصبح الحفظ يطبع الحجم بين 10 و120، والرندر يحوله إلى `50px` فعليًا.

### خصم كارت المنتج

الكارت يعرض الآن السعر الأصلي مشطوبًا، والسعر النهائي بوضوح، وشارة مثل `خصم 20%`. عند عدم وجود خصم تختفي العناصر الإضافية ولا يتغير شكل الكارت العادي. خصم الموقع النشط له الأولوية على خصم الموديل، ولا يتم جمع النسبتين. سجلات الطلبات القديمة تظل معتمدة على Price Snapshot ولا تتغير.

### التراجع في المرتجعات

زر الرجوع يظهر فقط عند وجود خطوة سابقة. كل ضغطة ترجع خطوة واحدة:

- الفحص `Good/Damaged` يرجع إلى انتظار الفحص، ويعيد القطعة إلى `Return Inspection` ويحذف سجل التلف الذي أنشأه هذا الفحص فقط.
- `Completed` يرجع إلى `Pickup On The Way` ويعكس المبلغ المرتجع وحالة الدفع واستخدام Dart Card أو استبدال سطر الطلب والقطعة البديلة ورسوم المندوب.
- `Pickup On The Way` يرجع إلى تعيين المندوب.
- تعيين المندوب يرجع إلى انتظار التعيين.
- الموافقة ترجع إلى الطلب المعلق وتفك حجز قطعة الاستبدال.
- الرفض يرجع إلى الطلب المعلق ويستعيد بيانات ما قبل الرفض.

قبل التنفيذ يظهر تحذير واضح، وبعده يُضاف حدث `RETURN_ROLLBACK` ولا يُحذف التاريخ السابق. البيانات القديمة التي لا تحتوي Snapshot تستخدم مسار توافق محافظ، أما العمليات الجديدة فتعود بدقة من Snapshot محفوظ قبل التغيير.

## فحص وتنظيف الملفات

- تم فحص 67 ملف HTML/CSS/JS.
- لا توجد ملفات Runtime فارغة أو نسخ متطابقة بـSHA-256.
- لا توجد روابط محلية مكسورة في HTML أو `url(...)` في CSS بعد احتساب أن روابط Fragments تُحل من جذر الموقع.
- لا توجد ملفات JS/CSS تشغيلية يتيمة غير محملة مباشرة أو ديناميكيًا.
- تم دمج القواعد غير المتجاوبة من `CSS/fixes.css` داخل `CSS/Stayle 1.css` فقط.
- لم يتم دمج أي ملفات JavaScript، ولم يُحذف أي ملف مشروع لعدم وجود حذف آمن لازم.
- أزيل Selector واحد خاص بالداشبورد كان متسربًا إلى CSS الموقع؛ نسخته الصحيحة موجودة في `Eye/dart.css`.
- `CSS/base.css` مطابق تمامًا للنسخة المرفوعة.

## الاختبارات

نجحت جميع اختبارات Node/Python غير المعتمدة على متصفح، ومنها: syntax لكل ملفات JavaScript، الحسابات المالية، المنصة، المندوب، المرتجعات، الإعدادات، التجميع، التتبع، SEO، HTML/assets/accessibility، وتسلسل CSS الجديد. كذلك تم تشغيل خادم محلي وفحص 50 ملف Runtime وكانت كلها تستجيب `200` وبمحتوى غير فارغ.

تعذر تشغيل اختباري Playwright المرئيين فقط لأن Chromium غير مثبت في البيئة. ملفات الاختبار ما زالت موجودة لتشغيلها على جهاز تطوير أو CI يحتوي Chromium.
