## النطاق والنتيجة

شمل الحصر ملفات CSS المصدر الاثني عشر للموقع والداشبورد، وترتيب تحميلها، وكتل التنسيق داخل HTML والتنظيمات المضافة من JavaScript. لم تتغير واجهات API أو قاعدة البيانات أو منطق JavaScript التجاري؛ لا توجد migrations.

حُذفت **198 حالة selector/property ملغاة**: 118 للموقع و80 للداشبورد. كانت القيمة الأقدم مغطاة بالكامل بقيمة أخرى لنفس المحدد ونفس الشرط، أو بقيمة `!important` لنفس المحدد. انخفض عدد تعريفات الخصائص في مصادر هاتين المجموعتين من 8,119 إلى 7,984؛ تُحتفظ بخصائص القواعد المشتركة للمحددات الأخرى التي ما زالت تحتاجها، دون نسخ الخصائص المتبقية.

يحتوي [سجل الحذف](css-audit/removed-declarations.json) على المحدد والشرط، والقيمة القديمة وموقعها، والقيمة الفعالة وموقعها. أرقام الأسطر فيه تخص المرجع السابق أعلاه. الملفات الحالية هي مصدر القيم الفعالة بعد التنظيف.

## قواعد المحافظة على الشكل

- بقي ترتيب تحميل CSS كما هو، وبقيت الخصائص الفعالة في مواضعها. لم تُجمع القواعد غير المتجاورة بنقل الخصائص إلى نهاية الملف.
- عند إزالة خاصية من بعض محددات قاعدة مشتركة، قُسمت القاعدة مع الاحتفاظ بترتيب التعريفات ودون نسخ بقية الخصائص.
- بقيت قواعد المقاسات وحالات `hover` و`focus` و`active`، والقيم البديلة لتوافق المتصفحات مثل `vh` ثم `dvh`، والخصائص ذات بادئات المتصفحات.
- بقيت جميع كتل `@media`: 12 للموقع و33 للداشبورد. التنسيقات داخل HTML وحقن JavaScript لم تحتوِ على تكرار ملغى داخل نطاقها؛ بقيت مواضع حقنها وحالات إظهار العناصر كما هي.
- لا يُحذف محدد لمجرد عدم ظهوره أثناء زيارة صفحة؛ قد يخص نافذة أو حالة صلاحيات أو صفًا يُنشأ لاحقًا.
- تبقى `CSS/main.css` و`CSS/base.css` و`CSS/responsive.css` مصادر الموقع. تُولد `home.css` و`home.min.css` منها؛ لا تُعدّل يدويًا.
- بقي استيراد أيقونات Boxicons الموجود أصلًا كما هو، حفاظًا على ترتيب تحميله وتوافقه.

## حجم CSS المرسل

المصادر منسقة للقراءة، ويزيل تجهيز `public/` التعليقات العادية والمسافات باستخدام ضغط مستوى 0؛ لا يعيد ترتيب القواعد أو تحسين القيم. تبقى تعليقات الترخيص التي تبدأ بـ `!` وروابط الملفات كما هي. الأرقام التالية قبل ضغط HTTP ولا تشمل الصور أو JavaScript:

| ملفات الموقع الثلاثة | 130,360 بايت | 95,172 بايت | 35,188 بايت — 27.0% |

## الفحص والصيانة

```bash
npm ci --ignore-scripts --no-audit --no-fund
npm run build
npm run audit:css -- --check
npm run audit:css -- --json
npm run check
DART_CSS_BASE_REF=HEAD node tests/css-cascade-browser.cjs
npm --prefix backend run check
```

يقارن اختبار المتصفح CSS القديم من مرجع Git مع CSS الجديد المُجهز للنشر على نسختين متطابقتين من DOM تُفتحان من البداية بنفس المقاس والحالة، في مقاسات 370 و480 و767 و768 و1440. يشمل الصفحات العامة وأقسام الداشبورد، ونافذتي المنتج والمقاسات والمجموعات، وحالات التركيز والمرور والضغط، وعينات لكل محدد حُذفت منه خاصية. يفحص القيم المحسوبة القياسية في القسم المعروض والعناصر الوهمية الفعالة وأبعاد العناصر والصور. تُثبت الحركة والمؤشر، ويُعرض محتوى `content-visibility` كاملًا في الطرفين لمنع توقيت الرسم الكسول من تغيير المقارنة؛ تُفحص آلية التحميل الفعلية في اختبارات الأداء الحالية. اختلاف كتابة متغير CSS الخام لا يُعد فرقًا بصريًا؛ تُقارن القيم الناتجة عنه. المقارنة المصورة تستخدم حد اختلاف لوني صفرًا وتستثني antialiasing لحواف الرسم فقط؛ تُسجل الفروق الخام أيضًا. الخطوط والخدمات الخارجية محجوبة بالتساوي في طرفي المقارنة.

في CI يُقارن `HEAD^` مع النسخة الحالية. عند إجراء تغيير تصميم مقصود لاحقًا يجب مراجعة فرق الشكل وتحديث اختبار الحفظ مع ذلك التغيير، بدل تعطيل فحص CSS كليًا.

اختبارات التكرار تغطي ترتيب القواعد، والمحددات المشتركة، واختصارات الخصائص، والأهمية، واختلاف المقاسات والحالات، وبقاء بدائل التوافق. أضيفت إلى الفحوص الحالية ولم تُغيّر شروط نجاح الاختبارات الموجودة.

نتائج المراجعة المحلية: **185 مقارنة بصرية ناجحة**، و**33 فحصًا ثابتًا ناجحًا**، واختبارات التشغيل العشرة الحالية ناجحة. يحتوي [سجل المقارنة](css-audit/visual-comparison.json) على الصفحة والحالة والمقاس وفروق القيم والصور وبصمة كل لقطة. فحوص الخادم `config/lint/typecheck` ناجحة، ونجح 435 اختبارًا؛ اختبارات PostgreSQL الـ47 تُشغَّل في CI بقاعدة الاختبار المخصصة. لا تُستخدم بيانات الإنتاج لهذه الاختبارات.
