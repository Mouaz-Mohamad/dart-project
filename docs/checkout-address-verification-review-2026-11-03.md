# Checkout address verification — 2026-11-03

A customer could submit the previous delivery destination while a new pin was still being reverse-geocoded. The former checkout wait handler also retried submission after eight seconds when old coordinates remained available.

## Result

- A map click, marker drag, manual lookup or GPS request immediately invalidates the previous verified destination.
- Map, manual and GPS results share a revision; stale successes and failures cannot overwrite the latest selection. Editing an unverified manual address also supersedes its pending lookup before the debounce ends.
- The Order button shows `Checking location…` and stays disabled during verification. Enter/programmatic submit is guarded. There is no automatic submission after a lookup or timer.
- Geocoding requests abort after 12 seconds; failed or unsupported destinations require retry. No old-pin fallback is used.
- A newly verified map destination updates the geographic address fields. Missing street/area values cannot retain the previous destination's fields; unit details remain editable.
- Checkout captures the verified address revision and fields, then checks them again immediately before the order POST after asynchronous pricing. A changed destination or unit detail requires confirmation again.
- The existing API, order idempotency key, pricing/stock authorization and database schema remain unchanged. No migration or new endpoint.

## Maintained sources and delivery

`src/storefront/address.js` now owns the shared map controller and builds to the existing `Js/dart-address.js` URL through the existing pinned minification build. This keeps the added correctness checks within the unchanged JavaScript performance budgets. `src/storefront/platform/checkout.js` owns the pre-POST guard; its platform delivery files were rebuilt. `Js/dart-checkout-stability.js` owns the button/capture guard. CI runs both new regression suites.

CSS delivery files were regenerated by the required full build from the existing CSS sources; no CSS source or design rule was changed in this task.
