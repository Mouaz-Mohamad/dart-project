1. استعادة عقد `DartState`: التعرف على بيانات العمل وقراءتها ومسحها من الذاكرة عند الخروج. لا حفظ لبيانات مالية في localStorage.
2. حماية مزامنة المجالات: snapshot وإصدارات تعديل محلية، صف واحد للحفظ، منع رد GET/PUT قديم من مسح تعديل أحدث، ومنع تداخل polling.
3. حفظ سجلات Expenses/Budgets/Invoices/Goals/Marketing عبر API فقط، وتحميل المجموعة الأصلية قبل الإضافة، ورفض الحفظ إذا كانت طبقة الحالة أو خدمة المزامنة غير متاحة.
4. أرشفة مؤكدة من الخادم، ومعاملة استلام COD المؤكد كنجاح حتى لو فشل تحديث البيانات اللاحق. فشل الإشعارات/التدقيق الأمامي الإضافي لا يخفي نجاح الحفظ المؤكد.
5. إعادة محاولة تنزيل وحدة Finance بعد فشلها: إزالة script الفاشل، وإظهار Retry بدل نافذة فارغة أو وعد معلق. إصدار روابط JS داخل الداشبورد لمنع استعمال الملفات القديمة بعد reload.
6. حالات التحميل والخطأ وإعادة محاولة التقارير؛ منع حلقات طلبات بعد الفشل ومنع ملخص قديم من استبدال ملخص جديد. إبقاء Add Marketing Record متاحًا حسب الصلاحيات أثناء تعذر الملخص. تحديث Draw Log عند hydration.
7. سلوك نماذج المالية: تركيز أول حقل، استعادة التركيز عند الإغلاق، Escape وTab داخل النافذة، ومنع إغلاق/إرسال النموذج مرة أخرى أثناء الحفظ.
