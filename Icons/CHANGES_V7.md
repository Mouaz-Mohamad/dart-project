# V7 changes

- Empty initial dashboard and removal of automatic sample catalogue initialization.
- Shared model/color image ownership and on-demand galleries.
- Model and physical-item editors matching the agreed data ownership.
- Automatic inventory groups and unchanged detailed item actions inside each group.
- Per-color storefront cards and synchronized full-model purchase dialog, color before size.
- Archived designs hidden; sold-out designs retained.
- Immutable past order prices and cart price-change confirmation.
- Read-only cross-tab synchronization to prevent stale dashboard writes during checkout.
- Scoped mobile group styling, prioritized section rendering and documented backend boundaries.
- Checkout success returns Home.
