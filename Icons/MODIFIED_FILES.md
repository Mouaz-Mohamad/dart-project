# Dart — فهرس الملفات المعدلة

هذا الإصدار يحافظ على الشكل الأساسي الحالي ويضيف أو يصلح وظائف الطلبات، العناوين والخرائط، بوابة المندوب، التتبع المباشر، استعادة كلمة المرور، الـLeaderboard، كود أصالة القطعة، تنسيق الأسعار، بيانات الملف الشخصي، ووصف الصور.

## صفحات الموقع والداشبورد

- `Eye/Dart Eye.html` — لوحة التحكم: الطلبات والخريطة والمندوبون والصور وطلبات إعادة ضبط كلمة المرور.
- `Eye/Dart Eye.html` — أضيف إليه أيضًا مودال واحد قابل لإعادة الاستخدام لتحرير جدول مقاسات الموديل.
- `rep.html` — تسجيل دخول/إنشاء حساب بنمط صفحة Sign In مع نموذج واحد ظاهر، ثم كروت طلبات كاملة العرض دون خريطة داخلية.
- `cart-checkout.html` — إتمام الطلب وربط العنوان بالخريطة في الاتجاهين.
- `track.html` — واجهة تتبع الطلب والمندوب والوقت المتوقع.
- `Sign Up modern.html` — طلب إعادة ضبط كلمة المرور وإجبار تغيير الكلمة المؤقتة.
- `profile.html` — تحسين بدائل الصور وربطه بعرض تفاصيل الحساب والطلبات والمرتجعات.
- `index.html`, `products.html`, `about.html`, `Contact us.html` — تحسين أوصاف الصور وإتاحة المحتوى.
- `index.html`, `products.html` — عرض جدول المقاسات الديناميكي داخل مودال المنتج.
- `products.html` — بحث وفلاتر مترابطة للمقاس واللون والتوفر والسعر والصنف مع الترتيب ومسح الفلاتر، داخل قسم مخفي يُفتح من زر واحد.
- `policies.html` — استعادة صفحة السياسات المطلوبة بواسطة روابط الموقع.

## JavaScript

- `Js/dart-address.js` — خريطة OpenStreetMap، البحث، reverse/forward geocoding والتحقق من العنوان.
- `Js/dart-platform.js` — العملاء والطلبات والخصم والملف الشخصي والـLeaderboard والـFeedback والحجز وكود القطعة وكلمات المرور.
- `Js/dart-rep.js` — حسابات المندوبين والصور والطلبات المتعددة وفتح Google Maps وحظر التسليم خارج نطاق 1 كم.
- `Js/dart-tracking.js` — خريطة تتبع العميل والمسار والوقت المتوقع وحالة عدم تعيين مندوب، مع استعادة أحدث طلب صحيح.
- `Js/one .js` — منطق السلة وإتمام الطلب والعودة إلى Home، وإظهار/إخفاء الفلاتر وجدول المقاسات.
- `Eye/dart-operations-v4.js` — عمليات لوحة التحكم الجديدة وترحيل البيانات المحلية.
- `Eye/dart-size-chart-v5.js` — محرر واحد لجدول المقاسات يُملأ ويحفظ حسب الموديل المحدد.
- `Eye/dart.js` — منطق لوحة التحكم الأساسي بعد إصلاح الأسعار والتعيين.
- `Eye/dart-fixes.js` — إصلاحات القيود والمبالغ.
- `sw.js` — إصدار كاش جديد لمنع تحميل ملفات قديمة بعد النشر.

## CSS

- `CSS/fixes.css` — تنسيق الخرائط وبوابة المندوب والتتبع والـLeaderboard ونوافذ كلمات المرور.
- `Eye/dart.css` — تنسيق إضافات لوحة التحكم مع الحفاظ على هويتها الحالية.
