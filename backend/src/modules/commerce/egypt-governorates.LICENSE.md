# Egyptian governorate boundary data

`egypt-governorates.json` contains the 27 ADM1 geometries from geoBoundaries
`EGY-ADM1-46179711`, reference year 2017, pinned revision `9469f09`.
All source vertices are retained without simplification, with coordinates rounded
to six decimal places (about 0.11 m latitude precision). Source names are mapped
to the store's canonical governorate IDs; irrelevant properties are omitted.

These administrative boundaries validate governorates, not individual streets,
city/neighborhood coverage, GPS accuracy, or the recipient's physical presence.
Addresses at changed administrative borders need review against updated data.
